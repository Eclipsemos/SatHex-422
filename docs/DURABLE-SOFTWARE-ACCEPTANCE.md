- 持久化已提交的软件槽、版本、容器ID、任务引用及容器所属标签；写临时文件、fsync、原子替换、目录fsync。
- 对目录持有Linux flock，拒绝第二个管理实例同时修改。
- 初始化校验软件槽仍在本地可信目录中，容器ID格式及实际Docker标签一致，拒绝控制不属于自己的容器。
- 激活前保存原已确认状态；进程在停止旧软件、创建候选软件后中断时，新实例按持久意图找到候选、清理未提交容器、恢复原软件。

- 普通close仅释放管理锁，不删除部署的容器；显式cleanup先持久化清理阶段，清理中断后可继续清除本标签资源。
