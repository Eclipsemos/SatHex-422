## 业务组件及本机接口

新增独立业务守护进程（建议名gs422-payload），维护文件目录、任务和接收状态；通信进程仅解析与投递、从内存缓存取遥测。短生命周期执行器通过Unix域socket向业务守护进程提交JSON请求，不把长任务留在执行器进程组内。已存在的执行器接口可以复用。

| 组件 | 责任 | 尚缺的外部接入 |
|---|---|---|
| 文件目录 | file_id分配、元数据、读写锁、校验、空间配额 | SSD挂载点可配置，不能假定有SSD |
| 接收服务 | 上注门控、部分文件、校验后提交 | 普通数据上注格式和输入通道 |
| 记录服务 | 星敏数据接收、按帧记录、落盘 | 星敏协议、数据端口和观测模式控制接口 |
| 固存服务 | 向外部固存请求指定文件/帧、校验接收 | 固存物理接口、请求/应答布局和CRC32参数 |
| 回放服务 | 选择已完成文件、限速、多链路投递 | 测控/数传输出通道和链路回压约定 |
| OTA服务 | 包接收、重组、文件验证、状态管理 | 内层校验约定、镜像签名、分区及启动回退 |
| 系统动作服务 | 有序重启、受控业务文件清理 | 本机特权调用，仅暴露固定动作 |

Unix接口建议：每次连接一项请求，4B大端JSON字节长度+UTF-8 JSON，请求最大8192B，响应最大4096B。仅接收授权本机UID，不开放TCP监听；参数中的file_id只查目录，不接受总线传入路径。错误回复为固定错误码和短原因，不能回传任意本机日志或命令输出。

## 指令处理与完成语义

协议接收成功、业务受理成功、后台任务完成是三个不同事件。当前原型的状态3和成功计数表示同步执行器成功返回。对长任务新增约定：执行器只有在持久化任务记录并获得job_id后才能成功；其返回data包含job_id、state。实际任务终态通过新增遥测页查询，不能把“指令完成”解释为整个回放或升级已经完成。

每个长任务用u32 job_id及u64 boot_id标识，进程重启不得重新分配仍在目录中的job_id。状态枚举：0空闲、1待执行、2运行、3等待输入/链路、4完成、5停止、6失败、7重启中断。停机后不会自动重跑清理、回放、固存读取或OTA写入；重启将未完成任务标记为中断，并保留进度。

| 条目 | 行为 | 成功条件与异常 |
|---|---|---|
| K1101 17H/01 | 开普通上注门控 | 输入端点已配置且能接收才报告可用；协议门控与端点可用性分开遥测 |
| K1102 17H/00 | 关上注门控 | 停止接受新包、关闭当前文件写入；未完成文件保留为partial，不进入回放目录 |
| K1103 17H/02 | 开OTA接收门控 | 与普通上注互斥；有活动接收时拒绝切换，先关闭/完成；不触发烧写 |
| K1109 84H | 有序重启 | 先拒绝新业务、终止活动任务、提交日志与文件、持久化重启意图，再调用固定系统重启接口 |
| K1110 13H | 清理接口模块业务存储 | 删除策略范围明确且文件未被占用；不清理系统、Docker、已验证待升级镜像或当前任务数据 |
| K1111 42H | 启动历史文件回放 | 40H链路配置和41H文件配置均有效，文件完成且不越界，输出端点全部可用；返回job_id |
| K1112 43H | 停止历史文件回放 | 取消读取和发送，确认所有输出worker停止后成功；未运行时幂等成功 |
| K1113 51H | 停止固存调度 | 取消外部请求并关partial文件；中止应答超时则报失败/状态未知，不假报停止 |
| K1114 52H | 固存状态查询 | 刷新/读取外部固存状态快照；21类仍无即时应答，通过结果请求读取；未接固存报7 |
| K1115 32H | 开/关星敏记录 | 开时验证输入、目标存储和模式；关时停止输入并提交已完整记录的数据 |
| D0351 04H | 接收OTA文件包 | 门控=2、结构和校验正确、包去重一致后写入暂存；完成接收不等于升级完成 |
| D0352 40H | 配置回放链路及筛选条件 | 16B参数原子保存到草稿；若回放运行则BUSY，不在运行中改变链路 |
| D0353 41H | 配置回放文件和帧范围 | 15B参数检查后保存；启动时再次核对文件和40H组合条件 |
| D0354 50H | 启动外部固存数据读取 | 6B参数按表解析并启动外部请求；不能当成直接读取本机eMMC文件 |

关门控对已进入分片重组、未进入业务执行的OTA也生效；最终执行前重新检查门控和会话身份。重组状态、落盘partial、业务上传会话需要统一取消，不允许切换门控后沿用旧会话的数据。

重启命令受理后可能来不及被主机查询，故开机遥测需要boot_id、上次重启原因及对应指令SEQ。不能把网络断开当成重启成功的唯一证据。停止/清理失败时，重启默认终止并报告失败，不强制断电；确需强制复位应由另行定义的星务/电源链路承担。

## 文件目录与存储管理

拟定元数据保存到本机持久目录，由管理员配置root；内存记录目录必须是显式大小限制的tmpfs，SSD记录目录必须验证为期望设备的挂载点。SSD不存在时明确报STORAGE_UNAVAILABLE，不悄悄写入根分区。本板目前无NVMe，仅可对临时测试目录开展软件验收。

目录记录：file_id:u32、类型（图像1/业务2/遥测3/日志4）、来源、存储介质、UTC起止时间、帧数、大小、内部SHA256、状态、是否固定保留、对应job_id。内部SHA256用于存储完整性，不替代总线累加和或外部CRC。写入流程为唯一partial文件→逐记录写入→flush/fsync→原子重命名→事务提交元数据；启动时处理未提交文件，不能把partial报告为完整。

本地记录建议每帧保存 `record_length:u32 timestamp_us:u64 payload_length:u32 payload:N CRC32:u32`，固定开销20B；record_length=16+N（不含自身4B），CRC32覆盖timestamp_us、payload_length、payload，采用CRC-32/ISO-HDLC、标准检查向量123456789→CBF43926，CRC字段大端。这是本地容器格式，不是外部固存/星敏帧格式。附加索引用于frame_index→文件偏移；恢复先扫描验证再重建索引。单帧长度上限由配置限制，禁止来自输入的长度导致无限分配。

K1110无参数，无法指定清理量，因此建议以本地策略执行：仅选择已完成、未固定、非活动读写的业务文件，按完成时间最旧优先，直到达到配置的最低空闲空间；未配置目标时拒绝，不默认清空。清理前持有目录锁，每个删除项先记入事务日志；跳过符号链接和未知文件。返回删除文件数、释放字节数及未达到目标原因。长期错误保留partial由单独离线维护策略处理，不能借无参指令无界删除。

## 历史回放

40H和41H构成一个草稿配置，42H将其冻结为任务快照；43H停止任务。41H文件ID优先选择一个已完成文件，40H类型必须与其相符。UTC区间建议两端包含，帧范围也两端包含，最终发送集合取两者交集。空集合拒绝，数据量按payload字节统计，不能超过选择范围的可用数据；表格没有规定0的特殊含义，本设计先将数据量0视为无效。所有这些组合语义属于新增约定。

速率1x/2x/4x以记录时间戳间隔为基准；无可信时间戳时需配置base_rate_bps，否则拒绝回放。跳变/倒退时间戳拒绝该文件，不能造成无限等待。采用令牌桶限制最大带宽；控制/遥测优先，不让回放堵塞2ms响应路径。

选择两条链路时，每条链路维护独立进度；任何所选链路不就绪时整个任务WAITING，等待超时转FAILED，不无声降级为单链路。已投递部分的链路不回退重发。输出“投递成功”与远端“接收确认”分开计数；未定义端到端ACK前，不把成功写入socket称为地面已收到。

DOCX要求本RS422从机不主动发数据，因而02H“测控链路”不能实现为主动串口推流。如果总体选择共用当前RS422，建议采用TYPE15/CODE20轮询数据、TYPE16/CODE20回复，单独设计ACK游标和重传；该数据下传协议尚未定版，本阶段实现输出适配器和模拟sink，不把业务数据塞入已有CODE00结果FIFO。数传链路同样保留端点配置，不能猜测IP或端口。

## 固存调度与星敏记录

D0354的8位文件号属于外部固存命名空间，不能自动等同本地u32 file_id。start_frame为参数2/3低高组合，count为参数4/5低高组合。表中“低8位00=读取全部剩余帧”存在歧义，本设计建议仅16位count整体为0表示全部剩余；如00 01则按256帧处理。需在接口评审中明确这一解释。

固存驱动先获得文件总帧数，再验证起始帧和请求数量；每帧核验外部帧长、序号及CRC，错误帧不落正式目录。外部CRC32多项式、初值、反射、xorout、字段覆盖范围均未给定，驱动保持未配置，不能套用本地记录CRC。遇丢帧是否重请求取决于固存协议；不默认用重新发送50H重启整个任务。

32H W1=1打开、2关闭，W2=0内存/1SSD，W3=1连续定姿/2广域/3重点目标。状态为IDLE→STARTING→RECORDING→STOPPING→COMPLETE/FAILED。开启重复请求若参数完全相同则幂等返回当前job_id，不重复创建文件；不同参数返回BUSY。关闭参数仍按表校验，不因关闭而接受非法枚举；未运行时合法关闭幂等成功。

观测模式不能只保存一个数字就宣称星敏已切换模式：输入驱动须确认上游支持并完成设置，或明确上游已选定对应模式。接收端不带控制能力时返回能力不足。环形缓冲满时停止该任务并报告丢帧计数；不默认覆盖最老数据。写入耗尽、介质消失或驱动断开进入FAILED并保留partial供诊断。

## OTA分阶段设计

04H按原表21B头+数据+4B校验解析，最大512B数据包通过已有TYPE29分片方案接收。门控、传输帧校验、包校验、文件校验、镜像可信性各自独立。状态：CLOSED→RECEIVING→RECEIVED→VERIFYING→READY_TO_APPLY→APPLYING→PENDING_BOOT→CONFIRMED，任一步可FAILED。

当前资料没有包内校验覆盖范围、ByteMap序列化规则、镜像签名和分区映射，故以下接口先实现抽象及测试替身：validate_packet、validate_file、verify_manifest、apply_image、confirm_boot。未绑定真实验证器的文件只能留在RECEIVED/UNVERIFIED，不能显示READY或烧写成功。

8位包序号下先支持最多256包、每包512B，即最大128KiB，绝不隐式回绕。实际Linux镜像通常需要更大空间，后续建议版本化扩展32位包索引及会话ID，不擅改现表。现表无上传会话ID，初始仅允许一个OTA会话；会话元数据固定后任何文件大小/总帧数/校验标识变化均拒绝，关闭门控后明确取消会话才能开始新文件。跨进程恢复不自动接受旧SEQ包，需从头重新上传或未来增加会话确认协议。

Excel没有独立“应用已验证镜像”指令。可选方案是本地策略在校验完整后自动应用，或后续增设应用命令；本版选择默认stage_only，禁止推测新的指令码。真正上线前需总体确定应用触发方式及厂商支持的A/B或恢复分区机制。业务文件暂存和系统分区写入分属不同权限服务，普通上注不能覆盖系统程序。

## 扩展遥测页面建议

保持已有TYPE11/CODE00请求与TYPE12/CODE00的60B BODY完全不变。新增页面请求BODY为空，仍回显SEQ；下面CODE仅为应用层页号，不是新增遥控指令。通信进程只读取后台缓存，不在请求路径读盘或请求外设。

| CODE | 页面 | 核心内容 |
|---|---|---|
| 01 | 业务概览 | boot_id、可用能力、门控、各任务状态与最后错误 |
| 02 | 本地存储 | 介质状态、总/可用容量、文件/partial数量、最近清理结果 |
| 03 | 回放 | job_id、文件ID、选中链路、帧范围、各链路发送/确认进度 |
| 04 | 星敏记录 | job_id、模式/介质、接收/丢弃帧数、字节数、当前文件ID |
| 05 | 固存调度 | 外部文件号、读取范围、CRC错误/缺帧计数、驱动状态 |
| 06 | OTA | 会话状态、总/已收包数、文件大小、验证状态、失败阶段 |

所有新页面BODY共用头：offset0 u16 SCHEMA=1；2 u16 PAGE_STATUS（0有效/1未配置/2缓存过期/3采集失败）；4 u64 BOOT_ID；12 u32 SNAPSHOT_AGE_MS；16 u32 VALID_FIELDS；20起为页面字段。AGE=FFFFFFFF表示从未获得快照。VALID_FIELDS逐字段标示，未知量写0并清有效位，不能用真实0表示未知。各页内错误码为u16，数值/位域大端。

01页BODY共44B：20 u32 capability_bits；24 u8 gate；25 u8 record_state；26 u8 playback_state；27 u8 storage_state；28 u8 ota_state；29 u8 reboot_state；30 u16 last_error；32 u32 last_job_id；36 u32 config_generation；40 u32 reserved=0。能力bit0普通上注端点、1记录、2回放、3外部固存、4OTA包校验、5OTA烧写、6本地清理、7重启；算法bit8永远0，留待后续。

其余页面字段按以下顺序紧密排列，所有偏移相对BODY，均含上述20B公共头：

| 页 | offset 类型 字段 | BODY/整帧长度 |
|---|---|---|
| 02 | 20 u8介质类型；21 u8介质状态；22 u16错误；24 u64总字节；32 u64可用字节；40 u32完整文件数；44 u32部分文件数；48 u32清理job_id；52 u32删除文件数；56 u64已释放字节 | 64/77B |
| 03 | 20 u32 job_id；24 u32 file_id；28 u8状态；29 u8链路掩码；30 u16错误；32 u32起始帧；36 u32结束帧；40 u32数传下一个待发帧；44 u32测控下一个待发帧；48 u64数传已投递字节；56 u64测控已投递字节；64 u64数传已确认字节；72 u64测控已确认字节 | 80/93B |
| 04 | 20 u32 job_id；24 u32 file_id；28 u8状态；29 u8存储类型；30 u8观测模式；31 u8保留；32 u16错误；34 u16保留；36 u64已接收帧；44 u64已丢弃帧；52 u64已提交payload字节 | 60/73B |
| 05 | 20 u32 job_id；24 u8外部文件号；25 u8状态；26 u16错误；28 u32起始帧；32 u32请求帧数；36 u64成功接收帧；44 u32 CRC错误；48 u32缺帧数；52 u32本地file_id；56 u8驱动状态；57..59保留0 | 60/73B |
| 06 | 20 u32 session_id；24 u8状态；25 u8验证阶段；26 u16错误；28 u32文件大小；32 u32总包数；36 u32不同包已收数；40 u32已验证数据字节；44 u32重复包数；48 u16最后包号；50 u8可信镜像；51 u8 stage_only；52 u32目标槽位ID | 56/69B |

VALID_FIELDS bit0起按各页上表字段顺序分配，跳过保留字段，不跳过状态/错误。01页按20起上述字段顺序分配，跳过reserved；布局schema与编码器使用同一份字段表以防错位。02页只报告当前配置的业务存储介质，多个介质的分页属于后续扩展；文件数量仅覆盖该介质。页03未提供端到端ACK时清除“已确认字节”有效位；结束后下一待发帧=结束帧+1，因此结束帧FFFFFFFF暂不允许。页05的CRC字段未定义时清除该字段有效位，同时驱动状态为未配置；页06目标分区不明时清目标槽位有效位，可信镜像=0，stage_only=1。会话ID为本地状态跟踪ID，不伪称其已存在于Excel上注参数。

新增页中的计数器溢出饱和至字段最大值并设置页面错误，不与旧CODE00已有模回绕语义混用。固定表之外的可变结果必须分页且整帧≤512B；不能靠截断数据满足长度约束。新增页不改变已有CODE00结果查询，执行器短结果与持续任务状态各有用途。

## 并发与恢复约束

清理与任何文件写入/回放读锁互斥；星敏记录和固存接收可同时运行，但共享空间预算和I/O限流。OTA实际烧写期间拒绝新记录、回放、清理；重启在所有业务退出和持久化完成后执行。所有等待有可配置上限，错误时保留状态证据。

控制SEQ仅16位，原型窗口去重不满足断电后永久防重需求。涉及重启、清理、OTA应用时需持久化指令指纹与结果；结合boot_id和未来会话标识确定重放边界，不能无限期拒绝合法SEQ回绕。该增强完成前不在实际板上开启这些动作。

## 实现顺序与验收

1. 本地业务目录、任务状态库、Unix接口及页面01/02；用临时目录验证配额、文件ID、断电恢复和有界清理，算法映射为空。
2. 记录/固存/回放通用worker与模拟输入/输出；验证空文件、范围边界、完整帧数据、双链路阻塞、停止和故障清理。模拟结果标明SIMULATED，不能启用真实能力位。
3. OTA暂存与分包去重、校验器接口和stage_only；拒绝256包以上、元数据冲突、校验缺失和路径逃逸，不写实际分区。
4. 厂商和总体接口具备后换入真实驱动，逐项设备联试。重启必须最后验证；保持厂家回退路径。
5. 更新草稿PR，用户确认全部约定和实测功能后才合并main。
