# 试验星01感算单机 RS422 应用层设计草案 v1

非算法业务的文件目录、生命周期、冲突规则、OTA暂存及扩展遥测页见[非算法业务设计](PAYLOAD-SERVICES-DESIGN.md)。该补充设计保持本文件已实现的基础帧不变；算法相关五项执行器按用户要求留空。

本分支根据用户提供的《天空智算星座试验星01星RS422串行总线协议》及《天空智算遥控大表_感算_修改版_20261118》设计。仅处理“感算K指令”第2–16行、“感算D指令”第2–5行，不将测控、电源、火工品等其他分系统指令发给本板。Excel 没有独立遥测布局，下面的应用层头、分片和遥测布局属于新增设计，需总体确认后定版。现有 AT 服务保持默认配置；实验二进制服务为独立入口，不能与 AT 服务同时占用同一 UART。

## 1 已规定的传输层

| 字节偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 2 | EB 90 |
| 2 | 2 | 有效数据长度 L，无符号大端，0–504 |
| 4 | L | 有效数据 |
| 4+L | 2 | 有效数据逐字节求和模65536，大端；不是 CRC |
| 6+L | 2 | 09 D7 |

整帧最长512字节。L=0在传输层可解析，但应用层拒绝。传输无转义，以长度定界；不能因为数据中出现 EB90 或 09D7 而截帧。损坏帧、超长长度、半帧超时后重新寻头，并计数。请求类型11返回12，15返回16；21、25、29、CC不直接应答。无自发遥测。

DOCX 要求奇偶校验位但未明确奇/偶、波特率及1/2停止位。本设计候选为115200/8E1，配置可选；当前已验收的 AT 服务仍为9600/8N1。未经总体确认不称为定版电气参数。2ms要求是“接收结束至开始返回”，不是整帧传完；Linux/Python不提供硬实时保证，必须实测并与总体确认，不能用单元测试冒充时序达标。

## 2 应用层分配（新增约定）

所有非分片帧有效数据：`TYPE:u8 VERSION:u8 SEQ:u16 CODE:u8 BODY:0..499B`。VERSION=1；SEQ由主机分配，回复原样回显。指令CODE沿用Excel十六进制码，不将K1101等十进制表号直接作为指令码。点对点链路不重复套CCSDS包头；Excel APID说明给出的PID=010101、PCAT=0001属于上层路由信息。

| TYPE | CODE | BODY及行为 |
|---|---|---|
| 11 | 00 | 空，获取基础健康遥测 |
| 12 | 00 | 基础健康遥测，下表 |
| 15 | 00 | 空，取最早的执行结果；结果只按请求返回 |
| 16 | 00 | `HAS_RESULT:u8`，有结果时跟 `SEQ:u16 CODE:u8 STATUS:u8 ERROR:u16 DATA_LEN:u16 DATA:0..490B` |
| 21 | Excel K码 | K无参为0B，短参严格6B，保留字节必须为0 |
| 25 | Excel D码 | D参数原始字节，长度和枚举严格检查 |
| 29 | 04 | OTA逻辑参数分片，下文 |
| CC | 任意 | 暂无广播内容定义，记录不支持，不执行副作用、不应答 |

接收计数统计校验通过的控制类有效数据（含重复及不支持的应用帧）。执行计数仅统计成功完成的逻辑指令；所有计数32位模回绕。最近结果保留在遥测中，结果FIFO有界，溢出计数可见。重复SEQ在有界窗口内不得再次执行；同SEQ不同内容记录冲突。串口复位保留窗口，进程重启清空，主机跨重启不得盲目重发重启/清理/OTA等指令。多帧OTA按分片内容去重，最后完整逻辑指令仍使用同一SEQ。

D0354的两个16位值在应用参数中按Excel明确的低/高顺序解析，不能对整个数组做大端交换；外层长度、SEQ、校验和仍为大端。该例外需总体确认。起止范围均检查不倒置；未说明的任务ID/优先级不猜测业务范围，由后端配置决定。

硬件/业务执行器接口采用本机配置的固定绝对路径 argv，通过JSON标准输入接收经过校验的指令，禁止从遥控参数拼接shell命令或路径。执行器必须返回JSON状态；不存在映射时回报 NOT_CONFIGURED，绝不以修改内存标志冒充完成算法、回放或烧写。调用有超时、输出限制与进程组清理；不自动重试非幂等操作。真实任务映射、星敏/固存/数传接口以及OTA分区/签名/回退约定待提供。此适配边界的代码与模拟测试不能替代对应设备联试。

## 4 OTA矛盾与分片建议

Excel D0351参数为21B头+N字节文件数据+4B校验，N=512时参数共537B，不能装进最大504B有效数据。本设计不扩大传输层上限：TYPE29 CODE04的BODY为 `ORIGINAL_TYPE=25:u8 TOTAL:u16 OFFSET:u16 CHUNK:1..494B`，TOTAL为原D0351参数总字节数。537B拆为494+43，整帧分别512B和61B。重组上限4096B，只保留一个正在重组的序列，支持乱序/相同分片重传，冲突重叠拒绝，5秒未完成丢弃。不写入文件直至完整参数通过校验。

OTA包内“数据长度”“ByteMap”“两个校验和”的覆盖范围及包序号回绕规则在Excel中未充分说明。v1验证固定头、长度不超过512、保留4B为0、文件大小/总帧数一致，以及8位包序号可表达范围（最大256帧）；原始两项校验值交由已配置OTA后端解释和复核。尚未定义大于256包的OTA文件传输；不默认回绕，也不自行将字段改为4字节。未确认前不配置真实烧写后端。

## 5 验证与发布

编解码测试覆盖大端、固定向量、最大帧、校验损坏、噪声、任意拆包/粘包、帧头出现在数据内、超长和半帧超时；命令测试覆盖19个表格条目（17H的三个别名共用编码）、保留位、非法范围、拒绝副作用、无即时应答、去重、结果查询、分片和后端失败。

Linux PTY验证线程和UART生命周期，实际COM3验证在独立实验服务运行期间执行，结束恢复已验收AT服务。实机不触发重启、清理或OTA烧写。分支开发和测试不能自动授权合并；最终由用户确认后才合并main。
