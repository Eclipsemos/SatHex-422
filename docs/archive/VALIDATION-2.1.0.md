# gs422 2.1.0：AT+CPU 验证

135 / RK3588 / ARM64，设备时间 2026-11-06 16:45 CST。

## 实现范围

新增 AT+CPU、AT+CPU?。后台约每秒采集，查询仅访问缓存。回复包括整机与每核使用率、
IOWAIT、1/5/15 分钟负载、在线核心数、各 cpufreq 核心组频率、复用的 SoC 温度和实际
采样窗口毫秒数。CPU helper 有 2 秒超时；缓存默认 5 秒过期；采集异常不会延长有效期。
其他指令与 2.0.0 一致，没有改传感器路径或除数。

## 已通过

- 19 项 Linux 自动测试：新增 CPU 差分、guest 不重复计数、IOWAIT 单独计数、计数回退、
  在线列表、缺失频率/负载、冷启动、TTL、失败恢复和热插拔预热。
- PTY 回归：慢 NPU 下 CPU 查询仍快速返回；CPU/STA 混合查询正确，非法 CPU 设置返回 ERROR。
- 原有 13 种新旧对照通过（STA 使用 2.0.0 起的新格式，其余回复一致）。
- 源码版及安装版均完成真实 CPU PTY 测试，单核定向负载限时 6 秒，无调频设置修改。
- 安装版测试：第 7 核忙碌时 CORE_USAGE=7:100.0%，整机 USAGE=19.9%；负载结束后
  第 7 核回落到 0.0%。其他后台任务使整机空闲测试读数仍约 8%。
- CORE_COUNT=8；频率组 0-3、4-5、6-7；温度与 STA 使用同一 SoC 采集缓存。
- CPU 真实 PTY 请求等待少于 0.5 秒；此值不等同物理 9600 波特的完整传输时延。
- 2.1.0 已部署，gs422.service active/enabled，启动日志 CPU/SOC/CURRENT/NPU 均有效。
- 正式服务独占 /dev/ttyS6；旧服务未启用。配置 SHA256 升级前后相同。
