## 本次功能

- IP1/IP2：静态 IPv4、掩码、网关、DNS、DHCP、配置查询、确认保存和回滚。
- SSH：状态、启动/停止、开机启动设置、端口修改。
- DISK：整盘列表、容量、文件系统挂载状态、总量、已用、可用及使用率，支持分页。
- 保留 STA、CPU、Wi-Fi 和 Docker 命令。

## 部署结果

- 保留 `/etc/gs422.conf`，升级时校验其内容未变。
- 管理地址保持 `192.168.5.135`，SSH 保持 22 端口。
- IP1 映射 `enP4p65s0`，IP2 映射 `eth0`。
- 存储识别两块盘：eMMC `mmcblk0` 116.48 GiB，NVMe `nvme0n1` 238.47 GiB。
- `mmcblk0p7` 挂载 `/`，`nvme0n1p1` 挂载 `/media/hzx/ssd`；`mmcblk0p6` 为未挂载 ext4。
- 升级前备份：`/home/hzx/gs422-backup-20261111-172717/installed.tar.gz`。
- 安装包可由 `python3 deploy/build_deb.py` 重建；`dist/` 不纳入 Git。
